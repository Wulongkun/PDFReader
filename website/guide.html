使用前必读：API Key 获取教程

拿到激活码后，按本教程配置即可使用全部在线功能

本软件的翻译和提取文本功能分别需要 DeepSeek 与 GLM-OCR API 的支持，请在软件设置里对应界面填写对应 API Key，其他功能可离线运行。

翻译模型配置说明

在软件设置的翻译模型界面填写以下三项；OCR 模型界面推荐填写 GLM-OCR 的 API Key。

Base URL https://api.deepseek.com/v1

使用 DeepSeek 时可填此地址；其他平台大模型需修改为对应地址

API Key 从 DeepSeek 开放平台获取

获取方法见下方 DeepSeek 章节

模型名 deepseek-v4-flash / deepseek-v4-pro / deepseek-flash

模型版本随时更新，需要以实际为准；其他平台需填写对应模型名

DeepSeek API Key 获取方法（翻译模型）

用于软件的翻译功能，按以下四步操作即可拿到 API Key。

  1. 1

    进入 DeepSeek 开放平台 platform.deepseek.com

    打开 DeepSeek 开放平台登录页。

  2. 2

    手机号验证码登录

    输入手机号，通过验证码形式登录，未注册将自动注册。

  3. 3

    点击充值

    登录之后点击充值，进入充值页面完成账户充值。

  4. 4

    创建 API Key

    点击 API keys，名称随便填，点击【创建】按钮，即可创建 API Key。

此 API Key 只展示一次，请务必复制后妥善保存，否则只能重新生成新的。

GLM-OCR API Key 获取方法（OCR 模型）

用于软件的提取文本功能，推荐使用 GLM-OCR，按以下三步操作。

  1. 1

    进入智谱 BigModel 平台 open.bigmodel.cn

    打开智谱 BigModel 平台登录页，支持 CCF 会员授权登录。

  2. 2

    进行账户充值

    首次可自定义金额，充 10 元即可。

  3. 3

    财务 → API Key

    点击财务 → API Key，点击确定，即可生成 API Key。
